# Vite Vue Travel Workbench Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the static frontend with a Vite + Vue 3 workbench that includes visible day-by-day LLM generation progress.

**Architecture:** Build Vue source under `frontend/src`, compile with Vite into static assets in `frontend/assets`, and keep FastAPI serving `frontend/index.html`. The browser calls the existing `/api/plan` endpoint and uses client-side simulated progress while awaiting the final response.

**Tech Stack:** Vite, Vue 3, TypeScript, Element Plus, lucide-vue-next, pytest contract tests, npm build.

---

## File Structure

- `package.json`: frontend scripts and dependencies.
- `index.html`: Vite development entry.
- `frontend/index.html`: production static shell generated by Vite.
- `frontend/src/main.ts`: Vue app bootstrap and Element Plus setup.
- `frontend/src/App.vue`: top-level workbench composition.
- `frontend/src/components/PlannerComposer.vue`: trip input form and example routes.
- `frontend/src/components/PlannerResults.vue`: result workspace, progress, itinerary cards, JSON panel.
- `frontend/src/services/planner.ts`: API payload/response types and request helper.
- `frontend/src/styles.css`: product visual system, layout, and responsive styling.
- `tests/test_frontend_contract.py`: asserts Vite/Vue contract and generation-process affordances.
